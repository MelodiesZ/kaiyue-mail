# 隐私与网络边界

默认配置下，凯越邮箱不需要 Mailspring ID，不轮询官方身份服务，不启动官方崩溃上传，不加载 Sentry 报告扩展，也不查询 Mailspring 更新源。官方身份 API 在请求层有显式阻断，避免隐式回退到 `id.getmailspring.com`。

已禁用依赖上游云服务或商业账号的包：活动分析、语法检查、翻译、联系人云端资料、会话共享、链接跟踪和打开跟踪。这一禁用清单由 `app/kaiyue-config.json` 集中管理，并由包管理器强制执行，旧用户配置不能将它们重新激活。用户主动添加非凯越账号时，客户端可与该邮箱服务商的 IMAP/SMTP/OAuth 端点通信；邮件中的远程图片与用户点击的外部链接也可能访问第三方。

邮件签名的社交图标使用内联标记，不从 Mailspring 服务器加载图片；“公司 Logo”上游查询已移除。OAuth 回调完成页由本机返回，不跳转到上游身份服务。

邮箱凭据通过现有密钥管理器使用 Electron `safeStorage` 加密，不写入中央配置。日志、测试失败输出和验收报告不得记录真实密码、token 或服务器管理员凭据。

如果企业未来部署自有身份 API、帮助中心、崩溃收集或更新服务，必须先确定数据主体、保留周期、权限和 TLS 配置，再通过 `app/kaiyue-config.json` 或对应的 `KAIYUE_*` 环境变量显式启用。
