# 系统通知

凯越邮箱在 macOS 和 Windows 上都使用操作系统通知服务。新邮件到达时，即使主窗口位于后台，通知也由 Electron 主进程提交给系统。

## macOS

- 通知显示在 macOS 通知中心。
- 支持打开邮件、归档、标为已读和快速回复等原生操作。
- 首次出现权限提示时需要选择“允许”。也可以在“系统设置 → 通知 → 凯越邮箱”中重新启用。
- 本地 ad-hoc 签名包适合测试；正式分发应使用稳定的 Developer ID 签名并完成公证，以保持应用身份与通知授权稳定。

## Windows

- 通知使用 Windows 原生 Toast，而不是应用内弹窗。
- 应用 AUMID 为 `com.kaiyue.mail`；开始菜单快捷方式带有同一 AUMID 和 Toast Activator CLSID。
- 点击通知或操作按钮会通过 `kaiyuemail://notification-*` 协议唤醒凯越邮箱并定位或处理对应邮件。
- 安装器会注册协议与快捷方式。便携 ZIP 在首次正常启动时也会注册协议，并创建仅用于 Toast 身份和回调的开始菜单快捷方式；不会额外创建桌面快捷方式。移动便携目录后应重新启动一次应用以修复快捷方式目标。正式部署仍推荐使用 `KaiyueMailSetup.exe`。
- 可在“设置 → 系统 → 通知 → 凯越邮箱”中检查权限，并确认“请勿打扰”或“专注助手”未屏蔽通知。

## 应用内开关

系统允许通知后，还要确保凯越邮箱偏好设置中的桌面通知已开启。默认配置为开启。如果系统通知没有出现，应依次检查应用内开关、操作系统权限和勿扰/专注模式。
